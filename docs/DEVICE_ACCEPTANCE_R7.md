# R7 实机反馈修复与验收

## 本轮修改

- 预览镜像开关：会话内保持；旋转后按屏幕左右翻转。发送照片不镜像，文字可读性不受预览开关影响。
- 视频默认闭麦，手动开麦后仍须点击录音开始/结束；普通语音通话默认行为不变。
- 摄像头可独立开关。关闭时释放设备、清待发帧和失效在飞抓帧，移除旧预览；打字、音频、TTS不挂断。已发送到供应商的图像无法撤回。
- 抓帧使用与通话控件一致的 HugeIcons.Camera01 线条图标。
- 基本视频设置前置，礼物独立分区。完整礼物提示词可保存、取消和恢复默认，空白回退默认。
- 仅视频请求的运行时提示词在输入模板转换后追加，防止模板删除或转义礼物标签说明；非视频请求顺序不变。这是已复现的一条缺陷，不声称是用户设备唯一原因。
- 双方已关联正文仅在通话卡显示；混合回复的思考/工具/媒体/礼物保留原有入口，编辑等操作仍使用原消息。VideoCallReply持久归属将同请求工具续轮与迟到助手ID纳入记录，不按时间猜关联，生成原文不删不重复。
- 流星雨44→96颗，固定粒子预算；银河铁道之夜增加双轨、枕木、三节列车、窗灯/轮组/前照灯。通话与设置预览都可跳过当前特效，继续队列。

## OPPO验收清单（尚未实机验证）

1. 初入视频显示闭麦，未操作时无录音；打开麦克风后点击录段，再点发送；普通语音不受影响。
2. 前后摄分别测试镜像和四个校准角度，检查文字方向、铺满无拉伸；切镜头/退后台/返回时关闭状态不能自行开启。
3. 回复中、录音中、待发送手动帧存在时关闭摄像头：预览消失，后续轮不使用旧图，文字/音频仍可发送；再开可恢复。
4. 普通聊天模型与支持图片/原音频模型分别请求赠礼，检查标签不裸露、礼物卡及动画正常；关闭礼物后不执行赠礼。
5. 完整提示词修改保存、取消、恢复默认；视频设置在前，礼物另组，窄屏可滚动。
6. 模型带思考/工具/礼物的回复挂断后正文不重复，通话记录能看全，原context只有一次；删卡恢复正文，切分支不误藏。
7. 连续同档流星和银河，跳当前立即播放下一件；快速跳过、不挡底层普通区域触摸；TalkBack可操作。
8. 明亮背景、横屏/窄屏检查镜像/开关摄像头/校准/跳过按钮无重叠，观察特效流畅度。
