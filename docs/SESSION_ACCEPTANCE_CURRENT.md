## 当前实现

- 视频：历史摄像头媒体在转换前后清理；唯一 USER 锚点与首次相机代次授权；关相机重开不续旧授权。预览卡固定 4:3，帧矩阵使用整帧等比 fit（不裁切、不非等比拉伸），键盘输入/动作可达。预览/JPEG 旋转镜像同步、几何版本拒旧帧；严格配对相机流比例，无匹配时明确失败。
- 连续帧：新安装默认「连续画面（每秒）」；旧每轮模式仍兼容。单调时钟约 1 Hz、最新 1..9 帧、12 MiB 原始字节上限，最多九宫格等比拼图，文件取消所有权清理。30/60 秒模式保留原定时语义，手动帧优先。
- 音频：按会话实际模型/provider 自动刷新；Gemini 与 GPT 音频家族的 ChatCompletions payload 回归；普通 GPT/Responses 不冒充音频。模型中途变化复查，缺音频明确说明。
- 多助手：独立窗口/模型/角色/压缩上下文、公平串行、冷却/预算/通知。参与助手列表已并入原主动消息页面；点助手行展开，只有打开“另设该助手”才显示冷却/每日任务上限/额外提示/活跃时段。手动触发会跳过自主冷却限制并把已有待执行任务提升为手动任务。发送/跳过决策即时写入本机后台运行记录；旧“暂停/停止”和每日模型预算界面已移除（遗留 paused 状态在进入页面或重新启用时清除）。完成消息先保存有界 CommitPending 载荷与确定性 ID，再进行 Room 幂等提交；主动任务排除未纳入预算的生图/插件/MCP 工具。WAIT 和无消息退避写入下一调度时刻。
- 聊天导出：图片导出恢复为聊天卡片风格（标题/头像/气泡/思考卡片/图片），按有界消息块分页渲染，避免旧版单张巨图；极长文本保留有界分页文字兜底。Markdown 逐消息流式写入后台、失败不假报成功。当前导出定向 16 项零失败，未真机复现最初闪退日志。
- 朋友圈：独立 ZIP，默认 3 条游标分页、搜索、详情/评论/点赞、草稿、受众 ACL、原生选图持久媒体/缩略图、聊天快照分享与头像资源。
- 宿主：受信任本地页面 + 主 frame + page token + 页面代次；原生能力授权、跨插件工具授权、受控媒体 origin、已有生图结果持久复制；API Key 不交页面。
- 助手任务：真实助手模型，当前动态与最新有界评论、隔离私聊；有限轮次/回复/调用/每日预算；原生设置/停止/助手发帖/待审列表；取消与同步写共用临界区。进程被杀不重跑。
- 主题：三套实际互动卡片源码配色、严格 bounded ZIP/重复 JSON key 检查、明暗/对比度、Material roles/shapes、设置卡片/侧栏选中/边框/静态阴影、WebView 最终颜色变量；保留用户背景和文字覆盖，恢复导入前主题。主题 ZIP 在插件导入入口也会被识别，显示主题选择并走原生设置应用，不再被误当成插件清单解析。
- 生命周期：停用与更新保留业务数据；卸载默认保留，可显式删除/先 SAF 导出，撤销原生授权并停止/释放任务。完整本地备份包含独立插件逻辑数据/媒体/任务设置，恢复旧任务不续跑；同步失败和启动恢复有定向 JVM 测试，真实断电/设备恢复未验证。

## 必须保留的限制

- 无连接 Android 设备；未完成前后摄/OEM 矩阵、键盘/短屏、发热/帧率、通知/锁屏省电、真实模型服务端端到端验收。
- provider 调用边界检查不能撤回已经发往服务端的字节；同步写先于取消完成时保留已提交结果。
- 无来源的既有匿名 data URI 无法可靠判断是否来自摄像头；新管线在匿名编码前清摄像头资源。
- 自动互评默认关闭，必须原生启用并选择参与者；不承诺被系统杀死后常驻运行。
- 已有生图结果可由用户确认导入；助手按需生图默认关闭，只在原生单独授权且已配置生图模型时生成最多一张、计入独立预算并要求预览审核。不把聊天/朋友圈原图像素默认喂给助手任务，亦不读取私聊。
- 云端产物与推送状态尚未验收，不将本地优化构建描述为精确 commit 云构建。
