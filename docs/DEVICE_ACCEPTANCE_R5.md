## 行为与实现边界

- 视频为普通逐轮请求：本轮帧图 + 可支持的 WAV 输入；不调用 Gemini Live/Realtime。打字常驻，点录音开始、再次点结束，TTS答复。
- 直传只对已实现的Google/OpenAI Chat Completions音频输入开放；不支持时ASR文字。语音识别可用性取决于所选provider和权限。
- 单段录音最长60秒；视频ASR停止后最多等待30秒转写。只用当前轮临时音频，不把WAV/base64留进历史上下文。取消、失败、请求结束释放自家文件。
- SiliconFlow视频ASR禁自身local VAD，不保留录音；普通聊天默认保留行为不变。其它provider内部自动结束机制未统一改造，需按实际provider验收。
- 通话气泡仅在角色与完整正文可从卡内访问时隐藏；媒体、工具保留。模型仍读取原消息一次，不另加重复transcript。迟到流式修订若不匹配持久快照，宁可保留气泡；详情按关联ID读取最新全文。不是全局尾保存barrier。
- 相机预览提供左转/右转/复位并保存。旋转后等比centerCrop；JPEG方向独立。未知机型不全局加90；设备建议只窄匹配OPPO、Reno14 Pro营销名、Android16；硬件型号代码未知时手动右转90。前后摄共用一个校准值，不代表均已真机确认。
- 视频设置独立可滚动页面；礼物开关默认关。开启后提示词从附加系统上下文注入，不依赖角色允许会话system prompt的开关；礼物不是独立ws_gift工具。
- 固定礼物ID为heart、bouquet、fireworks、meteor、galaxy_train。前两项Emoji气泡，后三项Compose Canvas动画，无外部贴图包。用户可改展示名/赠礼措辞，不能改执行ID，不涉及真钱交易。
- 主动设置的“后台活动记录”区域新增“查看主动唤醒记录”折叠入口，每行可点全文详情、滚动及选择文本；保留取消调度与原有最近会话活动入口。

## OPPO Reno14 Pro / Android16 / ColorOS16.0.5 清单

1. 先备份正式版；共存包独立数据，需自行导入。不要安装unsigned更新候选，不卸载正式版。
2. 检查竖屏前/后摄是否正立；若仍左转90，按右转并重进验证保存。切前后摄、横竖屏、退后台恢复；画面无黑边、圆形不拉伸、中心不偏。
3. 对同一画面改变预览校准并抓帧，确认模型接收图方向不跟人工校准额外转动。
4. 普通音频模型：点开始时停止旧朗读，再点结束后只提交一次录音；快速取消/重录、权限收回、焦点被别的应用夺走都不发送取消段。
5. 连录60秒确认限时。ASR点击停止后成功只提交文字；断网/超时不误发旧转写，重新录音正常。验证SiliconFlow视频缓存被释放且普通聊天历史音频仍可播放。
6. 打字始终可见，键盘弹出不挡发送；通话全文可回滚。挂断后卡内完整，普通聊天上下文能回忆内容但不重复。
7. 边流式回复边挂断，检查不会藏掉尾文字；若保守保留原气泡，文字仍应完整。删除卡/切分支时原消息可见。
8. 开礼物后在默认角色设置（不允许conversation system prompt）下请求赠礼，确认识别固定标签和动画，无“没有工具/审定ID”阻断。自定义名称/措辞保存后生效。
9. 视频设置小屏滚动可达底部。主动唤醒记录折叠/展开、点详情读完整长原因/结果，单看详情不改状态，取消仍有效。
10. 做一次纯语音通话回归：原自动监听、Mic/MicOff、扬声器路由及TTS无退化。
