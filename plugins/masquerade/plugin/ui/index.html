Model Connection

舞台的灯，接在宿主设置里

剧中台词与落幕时的压缩概要共用这一个模型通道，都不写入主聊天上下文。这一页只读展示状态；配置入口在宿主，不在这里另设一套，避免改了这边、那边还是旧值。

HOW TO
🔑 到橘瓣 设置 → 插件管理 → 假面舞会 填写「模型 API Key」「接口地址」「模型 ID」，或选好「备用模型」。改完保存、重新打开本页即生效。密钥由宿主以密码字段保存，本页永不读取、显示或导出。

自定义接口域名需同时出现在 manifest.allowedHosts 与 main.js 的白名单里；仅接受 HTTPS。未配置模型时不会生成任何剧中台词，也不会假装做了模型压缩——落幕概要会明确标注为本地摘录。

ISOLATION

整场戏的逐字台词只存在插件私有剧本与「演绎档案」里。落幕时，插件用内置模型把剧情压成一段概要，作为可见消息送进助手最新有对话的聊天；同时写一条明确标注「这是角色扮演游戏」的记忆，并把同一段说明作为本次请求的临时系统提示词。
