Model Connection

给舞台接一盏自己的灯

剧中对话走插件自带的模型通道，不写入主聊天上下文。这正是「平时还是真实关系」的关键。

HOW TO
🔑 API Key 由宿主以密码字段保存在「设置 → 插件管理 → 假面舞会」里。这个页面不会读取、显示或存储密钥；未填写时会尝试复用宿主模型选择器里已配置的备用模型。

自定义接口域名需要同时出现在 manifest.allowedHosts 与 main.js 的白名单里，改完重新导入插件即可。仅接受 HTTPS，避免密钥明文外泄。

ISOLATION

整场戏的台词只存在插件内部的剧本里。落幕时，插件会写一条明确标注「这是角色扮演游戏」的记忆，并把同一段说明作为本次请求的临时系统提示词送进聊天——助手因此知道刚刚是游戏，而这段规则不会永久改变它的语气。
