# UI 素材来源与许可

所有素材均随插件本地打包，运行时不请求外部 CDN，离线可用。

| 文件 | 用途 | 来源 | 许可 |
|---|---|---|---|
| `bow-cc0.svg` | 请柬四角装饰（凯尔特结蝴蝶纹样） | Openclipart / clipart.free，作者 GDJ，<https://clipart.free/clipart/celtic-knot-line-art-butterfly-2-278246> | CC0 1.0 公有领域，可商用、无需署名 |
| `ornament-cc0.svg` | 分隔线与标签花饰（flower outline） | Tabler Icons，<https://github.com/tabler/tabler-icons> | MIT |
| `cormorant.woff2` | 英文标题衬线字体 Cormorant Garamond | Google Fonts，<https://fonts.google.com/specimen/Cormorant+Garamond> | SIL Open Font License 1.1（OFL-1.1） |
| `mask.svg` | 假面面具主视觉 | 本项目自绘 | 本项目 MIT |

说明：`bow-cc0.svg` 下载自 `https://openclipart.org/download/278246/celtic-knot-line-art-butterfly-2.svg`；`ornament-cc0.svg` 下载自 tabler-icons 仓库的 `icons/outline/flower.svg`；字体经 Google Fonts CSS 取到 woff2 后本地化，仅用于标题排版，未修改字体文件。中文标题使用设备自带宋体/衬线字体回退，不外链中文字体以控制体积。
